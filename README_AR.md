# KIM ADDONS — مشروع أندرويد أولي قابل للبناء من الهاتف

هذا مشروع Android WebView بواجهة عربية سوداء/بنفسجية. يتضمن بحثاً وتصنيفات ومفضلة وإعدادات وقائمة تنزيلات محلية. كتالوج البداية تجريبي للتصميم؛ لا يحتوي على مودات خارجية جاهزة أو روابط تنزيل مزيفة. لإضافة مود حقيقي، أضف ملفاً مرخصاً تملك حق نشره إلى `app/src/main/assets/mods/` واربطه في `index.html` أو استخدم روابط تنزيل موثوقة تملكها.

## بناء APK من الهاتف عبر GitHub Actions
1. فك ضغط ZIP وارفع **محتويات المجلد** إلى مستودع GitHub جديد باسم `KIM-ADDONS-Android`.
2. افتح تبويب Actions وفعّل GitHub Actions إذا طلب ذلك.
3. أنشئ الملف `.github/workflows/build-apk.yml` كما هو موضح في هذا المشروع (إذا لم يظهر لأنه يبدأ بنقطة، أنشئ المجلدات والملف يدوياً).
4. ادفع التغييرات (Commit). افتح Actions ثم مهمة `Build KIM ADDONS APK`.
5. بعد نجاح المهمة، افتح تشغيل المهمة ونزّل Artifact باسم `kim-addons-debug-apk`، ثم فك ضغطه وثبّت `app-debug.apk`. قد تحتاج السماح بالتثبيت من هذا المصدر.

## ملاحظات صريحة
- هذا مشروع مصدر Android، وليس APK مبنياً مسبقاً.
- أول إصدار لا يتصل بخادم سحابي ولا يحتوي على تسجيل حسابات سحابية. المفضلة والإعدادات محفوظة محلياً على الجهاز.
- أزرار التصفح والبحث والتصفية والمفضلة والتنزيلات والإعدادات تعمل داخل الواجهة. التنزيلات الحقيقية تتطلب توفير ملفات إضافات حقيقية وروابطها.
- لا تنشر ملفات لا تملك حقوق إعادة توزيعها.
